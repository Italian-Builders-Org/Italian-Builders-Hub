# Italian Builders — Landing (Officina Modulare)

Landing ufficiale: una sola pagina, CTA community verso X (`@italianbldrs`).

## Stack

- Next.js (App Router)
- Tailwind CSS v4
- Fontself-hosted via Fontsource: Archivo Black, Archivo, IBM Plex Mono

## Comandi

```bash
npm install
npm run dev
npm run build
npm run start
```

## Contenuti

- Hero con **750+ membri**
- Sezioni manifesto / community (Telegram) / Magistra / principi
- CTA **Entra in community** → https://x.com/italianbldrs
- Nessuna pagina di join, submit progetti, waitlist o dashboard
